# 🐝 CodeHive - Landing Page

Bienvenido al repositorio oficial de la Landing Page de **CodeHive**. 
Somos un equipo de desarrolladores apasionados dedicados a crear soluciones web y móviles de alto rendimiento. Nuestra misión es resolver problemas reales de la sociedad y empresas privadas a través de experiencias digitales impactantes.

## 🚀 Sobre el Proyecto

Este proyecto es la carta de presentación de CodeHive. Está diseñado para ser rápido, moderno y totalmente responsivo. Incluye información sobre nuestros servicios, nuestro equipo y destaca nuestros productos principales, como la aplicación **VotaPE**.

### ✨ Características Principales

*   **Diseño Responsivo**: Optimizado para funcionar perfectamente en móviles, tablets y escritorio.
*   **Showcase Dinámico de VotaPE**: Carrusel automático que carga y muestra aleatoriamente las capturas de pantalla de la app.
*   **Sección de Equipo**: Tarjetas de presentación uniformes y estéticas para cada miembro.
*   **Optimización de Rendimiento**: Carga diferida de imágenes y activos optimizados para máxima velocidad.
*   **SEO & Social Sharing**: Configuración completa de Open Graph para vistas previas en redes sociales (WhatsApp, Facebook, LinkedIn).

## 🛠️ Tecnologías

Este proyecto está construido con herramientas modernas para garantizar escalabilidad y rendimiento:

*   **[React](https://react.dev/)**: Librería principal para la interfaz de usuario.
*   **[Vite](https://vitejs.dev/)**: Build tool de próxima generación para un desarrollo ultrarrápido.
*   **[Lucide React](https://lucide.dev/)**: Iconografía moderna y ligera.
*   **CSS Modules / Variables**: Estilos modulares y sistema de diseño basado en variables CSS.

## 📦 Instalación y Uso

Sigue estos pasos para ejecutar el proyecto en tu entorno local:

1.  **Clonar el repositorio**:
    ```bash
    git clone https://github.com/ronaldsalazarvasquez/CodeHive-Page.git
    cd CodeHive-Page
    ```

2.  **Instalar dependencias**:
    ```bash
    npm install
    ```

3.  **Iniciar servidor de desarrollo**:
    ```bash
    npm run dev
    ```
    El sitio estará disponible en `http://localhost:5173`.

4.  **Construir para producción**:
    ```bash
    npm run build
    ```
